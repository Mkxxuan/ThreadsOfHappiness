# 幸福的丝线 · Unity 实现（ThreadsOfHappiness）

桌面推理桌游《幸福的丝线》的 Unity 数字版。支持**单人选边对抗 AI** 与**双人同屏热座**。

## 如何运行

1. 用 Unity Hub 打开本文件夹（`ThreadsOfHappiness/`），Unity 版本：**2022.3.62f3c1（中国版）**
2. 打开 `Assets/Scenes/Main.unity`（任意空场景也可以）
3. 点击 Play —— 整个游戏界面由代码在运行时自动搭建

## 规则速览

- 25 名少女按房间号 201~605 排成 5×5 宿舍；百花开（403 房，正中央）开局即变为《幸福》状态
- 附身随从阵营秘密指定 3 名随从（不可选百花开，IF 路线可选）
- 每回合循环：
  - **主人公阶段**：放置 3 个监视指示物（第 1 回合跳过）；被监视的随从本回合不能行动
  - **附身随从阶段**：亮出 1 张预告牌（一蓝一红×2 / 两蓝 / 两红 / 两蓝一红），按礼物范围把存活者变为《幸福》状态
    - 红色礼物：周围 8 格；蓝色礼物：同行同列直线
    - 每个随从每回合只能转换 1 人；必须尽可能转换到预告人数，做不到的部分作为"未使用礼物"交给主人公（泄密！）
  - **结束阶段**：指示物翻面
- **胜负**：
  - 主人公方胜：某个附身随从阶段，随从方完全无法转换（3 名随从同时被监视 / 范围内无目标）
  - 随从方胜：撑到第 6 回合主人公阶段后，至少 1 名随从未被监视

## 功能

- 单人 · 主人公方 vs AI 随从（怀疑度辅助显示）
- 单人 · 附身随从方 vs AI 主人公（约束推理）
- 双人 · 同屏热座（换手遮罩防偷看）
- AI 难度：简单 / 普通 / 困难；IF 路线开关
- 完整行动日志、预告牌公开信息区、终局揭示

## 工程结构

```
Assets/Scripts/Core/       纯 C# 规则内核（不依赖 Unity，可脱离引擎测试）
  ├ GameTypes.cs           配置、角色/预告牌数据表
  ├ GameState.cs           对局状态与回合记录
  ├ RulesEngine.cs         全部规则校验与执行
  ├ BeliefSet.cs           主人公方候选三元组推理
  └ AI/                    双方 AI + 自对弈引擎
Assets/Scripts/Runtime/    Unity 表现层（代码动态搭建 UI）
SimRunner/                 （工程外）dotnet 控制台：45 项规则测试 + AI 模拟
```

## 修改角色名单

`Assets/Scripts/Core/GameTypes.cs` 中的 `DefaultRoster()` 是占位名单
（只有百花开、阳矢、桃子、萤等 11 个名字来自规则书，其余为占位），直接改这个数组即可换成实体卡数据。
